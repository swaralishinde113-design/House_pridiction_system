# House Price Prediction System

## Overview
This project predicts house prices using Machine Learning based on features such as area, location, number of bedrooms, and bathrooms.

## Features
- House price prediction
- Linear Regression model
- CLI-based interaction
- Data visualization
- Model saving/loading using Joblib

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Joblib

## Dataset Features
- Area
- Bedrooms
- Bathrooms
- Location
- Price

## Machine Learning Workflow
1. Data Collection
2. Data Preprocessing
3. Feature Engineering
4. Model Training
5. Model Evaluation
6. Prediction

## Evaluation Metrics
- MAE (Mean Absolute Error)
- RMSE (Root Mean Squared Error)

## How to Run

### Install Dependencies
pip install -r requirements.txt

### Train Model
python train_model.py

### Run Application
python app.py

### Run Visualizations
python visualization.py
